# AI 使用与责任

2026-10-25：Codex 按维护任务书辅助实现安装诊断、MoonBit 报告摘要/JUnit、全文件差异与项目回归管理、类型化调用和发行候选准备。自动化确认状态测试不代表真人审核期望；工作区消费者不冒充注册表采用。具体结果及外部缺口见 MAINTENANCE_PROGRESS.md。

本项目在用户确定选题及规格后，由 Codex 辅助实现 MoonBit 源码、测试、CLI、文档及参赛草稿。

2026-10-17 的申报修订及同类项目比较也经过 Codex 辅助，未声称正文由参赛者独立人工撰写。当前章程要求人工撰写一页 Markdown，因此自动审阅仅核对事实、内容覆盖和边界，不能替代参赛者的人工写作要求。

AI 辅助不替代验证：使用实际固定版本编译器运行 native 编译和测试；合法编辑序列期望由独立 Microsoft 参考实现产生；手工核算 Unicode 与换行例子；CLI 验收检查实际退出码、报告与异地复现。

没有通过 AI 服务处理会话的产品功能，运行时不需要模型 API 或网络。开发期下载官方工具链、依赖和参考包需要网络。

参赛者需要理解并能解释：UTF-16/码点/字素区别，didChange 顺序，事务回滚，未知状态恢复，检查点证据边界，独立参考的缓存观察及对应生成策略。提交前应自行审阅源码、依赖许可和材料，对成果负责。

不得将自动生成材料中的计划当成已验证结果。实际运行证据见 VALIDATION.md 与 validation-results.json；公共发布和报名状态必须由真实操作确认。

2026-10-20：Codex 根据用户提供的两条实质审查反馈，辅助新增日志适配器、批量文本编辑预检、回归用例、VS Code 接入、发行打包和相应文档。真实宿主测试通过实际 VS Code Extension Host API 执行，使用内置提供者生成编辑，并由宿主实际应用结果独立对照；它不是人工试用。JSON-RPC trace 使用固定开发依赖与实际服务器通信生成。故障注入及 URI 归一化分别披露；未声称发现第三方漏洞或取得维护者采用。申报草稿仍需参赛者按现行要求人工理解、修改和定稿。
