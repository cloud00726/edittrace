# 同一任务的工作流对照

2026-10-20。范围：本轮实际完成的本地任务；没有对第三方工具做安装、速度或完整功能评测。

微软 LSP Inspector 的公开 README 描述日志加载、消息参数展开和筛选；不能据此推断其他工具均无文本重放/回归能力。来源：https://github.com/microsoft/language-server-protocol-inspector 。

| 任务 | 人工查看日志仍需完成的工作 | 本轮实际产物 |
|---|---|---|
| 从真实同步输入还原 Unicode 编辑 | 逐步计算 UTF-16 范围和文本 | import 后 audit；实际事件与 4 个宿主快照比较 |
| 验证 JSON 格式化编辑 | 检查同基线编辑范围并应用、比较 | check-edits 给出预检与实际文本匹配 |
| 验证跨文件重命名的文本变更 | 遍历各文件、应用提供者编辑 | 两文件预测/actual 比较，明确不验证资源操作和基线版本 |
| 修复后保留检查 | 手工重新执行并解释预期 | 自包含 case 与 suite；过期版本复现和漏事件失败路径 |
| 把同步问题交接给另一人 | 准备基线、操作、预期及说明 | 原复现包或文档筛选包重验；用例迁移目录运行 |

上述表是操作/产物对照，不是已测出的效率提升。没有真人接入计时；没有第三方性能对比；日志查看工具与 EditTrace 可以互补。自动预检、宿主结果对照和持续回归闭环的实际组合是本轮新增可验证价值。
