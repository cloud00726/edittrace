# EditTrace core — 0.3.0 source candidate

MoonBit UTF-16 text edit verification, document synchronization replay and portable regression assertions. Source: https://github.com/cloud00726/edittrace . License: MIT; dependency/reference attribution: THIRD_PARTY_NOTICES.md.

This archive was generated by the pinned `moon package` from an explicit source allowlist. It is a **local candidate**, not proof of Mooncakes publication. The module still uses `local/edittrace` pending verification of account ownership and coordinated import migration.

Public packages: core/text, core/edit_plan, core/session, core/case and core/report. See docs/API.md for signatures, typed EditResult and migration. Existing apply and Json interfaces remain available.

```moonbit
// Import the verified published module's core/edit_plan package as @edit_plan.
fn main {
  match @edit_plan.evaluate("unchanged", []) {
    Applied(text) => println(text)
    Rejected(_) => panic()
  }
}
```

Pure computational packages have been consumed on native and JS in a separate local workspace. The CLI requires native IO through moonbitlang/async 0.22.5. This does not claim the CLI or all packages support every backend.

UTF-16 text-only scope: the tool does not establish program semantics, provider resource operations or server memory. Regression expectations must be chosen explicitly; reproducing an expected fault can itself be a passing test. Input and resource limits apply. See docs/PROTOCOL_NOTES.md and docs/LIMITATIONS.md.

The staged archive excludes local toolchains, credentials, binaries, host profiles and historical execution reports. VSIX and platform binary distribution are separate artifacts. Microsoft textdocument/jsonrpc are development references, not npm runtime dependencies of the CLI.
